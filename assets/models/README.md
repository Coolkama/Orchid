# Test models

This directory contains public, disposable character assets used to exercise Orchid's modelling, rigging and animation tooling.

The current reference asset is expected at:

`assets/models/glimmerkin.glb`

Glimmerkin is a purpose-built Orchid test creature rather than a production application character. Its oversized head, short limbs, tail and multiple head appendages make it useful for testing non-humanoid rigging, deformation and secondary motion.

Keep imported source assets intact. Derived meshes, renders and Blender files should be generated into workflow artifacts rather than overwriting the source model.
